## Platform

web

## Users
- **Primary Audience:** Technical recruiters, engineering hiring managers, CTOs, and technical leads seeking full-stack and backend software engineers.
- **Situation:** Evaluating candidate capability, engineering maturity, code architecture, and problem-solving depth for high-impact roles (remote, hybrid, or on-site).
- **Core Job:** Quickly verifying real-world software delivery experience, technical competence across full-stack and systems integration, and reviewing concrete evidence (live demos, GitHub repos, CV download/print).

## Product Purpose
The portfolio serves as the definitive personal and professional showcase for Trần Ngọc Huy. It exists to demonstrate end-to-end engineering excellence, communicate real-world enterprise delivery experience, and facilitate direct hiring outreach. Success means high conversion from visitor browsing to CV downloads, code/project inspections, and direct contact inquiries.

## Positioning
**Enterprise Systems Builder with AI Integration:** Unlike conventional developer portfolios showing only tutorial projects, Huy demonstrates 2+ years shipping complex enterprise ERP/CRM features, third-party connectors (Shopify, Magento, Viva Payment, SaaS EBP, etc.), REST APIs, and ESB2/webhooks for European enterprise clients (Lundi Matin Groupe, France), backed by hackathon first-prize awards (DUT Hackathon 2023 by KMS Technology) and practical Google Gemini AI production implementations.

## Operating Context
- Visitors review the portfolio on desktop and mobile browsers during hiring screens, recruiter outreach, or interview debriefs.
- Visitors frequently toggle between the interactive web showcase and the dedicated resume view (`/resume`) with print/PDF export workflows.
- Code repositories on GitHub and live project deployments (Vercel, Netlify) serve as external verification destinations.

## Capabilities and Constraints
- **Core Capabilities:**
  - Interactive hero, bio, career timeline, projects showcase, awards list, technical skills breakdown, and direct contact options.
  - Dedicated Drupal & CMS client project portfolio section.
  - Dedicated printable/downloadable resume route (`/resume`) with clean print stylesheet layout and sync with `Tran-Ngoc-Huy-CV.pdf`.
  - Dark/light mode theme support (`next-themes`).
- **Technical Constraints:**
  - Next.js 16 (App Router), React 19, Tailwind CSS v4, Framer Motion, Lucide React icons.
  - Static/hybrid export readiness; fast load times without heavy server state requirements.
- **Terminology:**
  - Full-stack Developer, ERP/CRM/CHR systems, ESB2 events, connectors, MCP, REST APIs, Webhooks.

## Product Principles
1. **Evidence Over Assertion:** Back every technical claim with a concrete repository link, demo URL, real company context, or competition proof.
2. **Clarity and Fast Scanning:** Technical recruiters scan in seconds; key competencies, role history, and project impacts must be immediately legible.
3. **Enterprise Rigor:** Reflect the engineering discipline required for large-scale systems (clean types, robust architecture, error resilience).
4. **Seamless Resume Continuity:** The interactive digital experience and the printable CV document (`/resume` and PDF) must tell one unified, consistent story.

## Accessibility & Inclusion

- Full keyboard navigation for all interactive links, modal lightboxes, and theme toggles.
- Proper semantic HTML structure (`header`, `main`, `section`, `nav`, `footer`) and clear alt text for project images and partner logos.
